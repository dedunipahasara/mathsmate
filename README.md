# MathsMate – Thamasha Deduni

Sinhala-first O/L Mathematics learning website containing only the lessons covered in the current study session.

## Run locally
1. Extract the ZIP file.
2. Open the `mathsmate` folder.
3. Open `index.html` in Chrome or another modern browser.

No login, server, database, or build step is required. Progress is saved in browser local storage.

## Included lesson areas only
- Algebra: the algebra topics and worked examples prepared from the supplied notes (expressions, equations, factorisation, algebraic fractions, simultaneous equations, quadratic equations, completing the square, quadratic formula derivation, inequalities and algebraic LCM).
- Fractions: equivalent fractions, simplifying, addition, subtraction, multiplication, division, mixed fractions, common denominators and extended word problems.
- Central sectors: area, arc length, perimeter, formula derivations and composite-shape questions.
- Volume of solids: cube, cuboid, cylinder, prism, cone, sphere, hemisphere and combined-volume questions, including cone–cylinder and sphere–cylinder relationships.

Unrelated subjects such as percentages, ratios and statistics have been removed. Surface-area lessons and formulas are not included in the solids lesson; it focuses on volume only. Diagrams are used only where they directly support the relevant lesson.
